One freshly coined English word, with its one-line definition: **fridgehope** — the hope that opening the fridge one more time will reveal food that was not there before.

> fridgehope (n.) The hope that opening the fridge one more time will reveal food that was not there before.

## How it works

`main.py` (Python 3 standard library only) writes the coinage to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 140 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
